# karma-network-site

karmanetwork.org - the public record of the Karma protocol: the rules, the ledger, who controls
what, and what changed. Read-only. Sells nothing.

**Not built yet.** This repo currently holds only the brief:

| File | What |
|---|---|
| `brief/CONTEXT-for-a-fresh-chat.md` | Read first. Who is who, how this project ships, copy and privacy rules, and where the prototype's rules differ from the live chain. |
| `brief/karmanetwork-build-plan.md` | The build plan: stack, routes, data layer, steps, definition of done. |
| `brief/karmanetwork.html` | Working single-file prototype of every page: exact design, copy, and a seeded dummy-data generator. Port it; do not redesign it. |

The app is built at the repo root. `brief/` stays as reference and is never served.
